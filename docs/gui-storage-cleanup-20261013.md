本机正式使用版 **1.2.1 / build 5** 已更新安装到 `/Users/luzove/Applications/BurnLight.app`。左下角新增“清理本地存储…”，先展示实际占用、任务清单和保留原因，选择后确认永久删除。本轮只对隔离测试材料执行删除；真实历史材料只做预览和取消确认，没有清理，也没有写盘。

## 使用与范围

- **临时缓存（保留历史）**：清理已有完整归档的临时日志、镜像、读盘缓存和输入快照。历史归档和任务摘要保留，恢复时仍需验证归档内容。
- **历史任务材料**：清理已结束任务的归档及临时副本，保留小型任务摘要、状态及导出目的地；材料清理时间明确显示，诊断导出随之停用。
- 保留期可选全部已结束任务、7 天以前、30 天以前；历史模式默认 30 天。变更选项使旧清单失效，需要重新扫描。逐项勾选、全选、全不选均可用；空选择禁止删除。
- 实际删除前再次确认数量、预计占用以及是否保留归档。没有后台自动清理，也不需要管理员认证。

只处理 GUI 任务索引指向的当前用户私有 `burnlight-job-UUID`、`burnlight-input-XXXXXX` 和对应 `Archives/UUID`。未索引的临时目录、仓库 `artifacts`/构建目录、安装包、源文件和用户导出均不纳入。此功能不是系统范围的磁盘清理。

当前任务、当前输入/预览依赖、活动/未知执行器、待检查及未确认成功的刻录任务保留。任何坏任务索引阻止整个清理；不通过清理解除刻录锁定。部分归档缺项时，临时原材料保留并显示原因；一个任务的部分归档不阻止其他完整任务的清理。共享快照核对全部引用任务，仍有受保护引用时保留；需要保留的归档在删除快照前实际复读验证 hash。

占用按 `st_blocks` 估算，稀疏镜像按实际分配块统计，共享快照只算一次。APFS 克隆、系统快照及硬链接可能影响最终释放空间，因此清单和结果使用“约/预计”，不把逻辑文件长度等同于可释放空间。
