# BurnLight 本机使用说明

Apple Silicon / macOS 26，保留 macOS 系统管理员认证；没有 Developer ID、公证或常驻 helper。密码只在系统认证对话框输入。构建时可选择只读或启用刻录，应用内以标记和按钮状态为准。

1. 连接光驱并刷新，单驱自动选择；多驱明确选择目标。点击“检查介质与目录”，读取最新完整 Session。所有物理命令（包括只读）一次只运行一个。
2. 选择本次输入目录，GUI 以当前用户权限建立只读快照，不依靠 root 读取 Desktop/Documents。保留相对路径，排除新增 `.DS_Store`，拒绝符号链接及特殊文件。
3. 点击预览。空白盘使用 init-build；已有完整可追加盘使用 build。遇到同路径普通文件会列出名称，并选择本次全部“跳过”或“替换”；同名目录合并，类型及大小写/Unicode 名称碰撞仍拒绝。全部跳过且没有新增内容时停止。替换只改变最新 Session 的文件引用，旧 Session 数据不会被擦除，并消耗新的容量。
4. 预览成功后才能确认“首次刻录”或“追加刻录”。核心重新扫描介质、检查身份/地址/容量/metadata/hash，选择 CD/DVD 参数，写入、关闭 Session，再从实际光盘校验镜像与文件内容。进度不确定，日志在命令结束后读取；不要拔盘或关机。
5. 写后失败进入检查，绝不自动重烧。先检查介质，再选择失败任务原 ISO 和同名 manifest 做“原镜像只读补验”；原材料及旧 cache 依赖必须保留。未知执行器只能凭明确退出收据和正常系统状态恢复；不硬杀 writer/osascript，不强制解锁。
6. 选择盘内文件/目录并“导出所选到本地”，未选择时可导出全部。光盘内容复读校验后，GUI 以用户权限复制到独立本地目录并复核大小/hash，不覆盖本地文件。失败 `.partial` 目录保留诊断。
7. 历史可打开任务材料或导出诊断，默认存放 `~/Library/Application Support/BurnLight/`。诊断含原始输入和本地路径，不自动上传。任务材料可能较大，不自动清理失败材料。
8. 实际读回通过仍需 Windows 实机验证；“导出 Windows 清单”保存本次预期目录/hash，使用项目 PowerShell 验收脚本在真实 Windows 光驱核对。本机与历史 CLI 结果不能代替新任务 Windows 结果。

1.2.1 正式本机使用版支持受限 CD-R/DVD-R UDF 2.01/VAT 的读取、导出与追加。本机 Lenovo XL6M DVD-R 已完成 Mac GUI 追加、Windows 读取并再次追加、Mac 实际返回读回。Windows 兼容视图仍明确提示格式偏差；每次写入继续核对设备与介质，并实际读回验证。首次刻录继续 ISO9660/Joliet；RW/BD、其他 UDF 映射与 VAT recovery 不支持。

UDF 2.01/VAT 检查显示真实版本，预览与导出绑定当前 VAT 视图。已证明的 Windows 目录位置偏差会显示“Windows 目录兼容视图”，并记录在诊断和导出收据中；其他损坏、CRC 错误或无法证明的引用仍拒绝。旧文件保持原实际地址；替换仅更新最新目录的引用。介质读取错误会停止操作，不能跳过旧文件后声称全盘验证成功。替换盘已完成 Windows 返回读取和正常 vat9 再追加后的四文件实际读回/导出；最新新目录无需兼容分支。用户已确认最新 Session 4 的四文件在 Windows 均可见且能打开；Windows 自动 hash 报告未采集，原损伤八 Session 全文件读取仍未通过。首刻继续生成 ISO9660/Joliet。只读结束后介质节点暂时消失时，核心会等待同一光驱重新发布介质，最多 10 秒；不会因此重试刻录。

窗口可在任务中关闭再打开，但任务继续；应用会拒绝在任务活跃或未知时退出。应用/后端的构建、安装、更新也会拒绝活跃或未知任务。不会修改永久系统安全设置。

返回盘的最新 Session 地址必须同时得到核心 msinfo/minfo 一致确认；矛盾时最多重查三次只读地址，仍矛盾则停止。GUI 也核对 inspect/list 的 Session、地址与容量，防止显示旧 Session 目录；检查失败时请保留日志重新检查，不要重烧。

Windows 小型 ISO/Joliet Session 的导入允许少于 32 blocks 的卷，文件系统识别按已知输入边界读取。新镜像仍采用原 writer 的大小、目录、extent 和 hash 校验。

## 清理本地存储

左下角“清理本地存储…”先扫描占用，按任务选择，再确认永久删除。默认“临时缓存（保留历史）”清理已有完整归档的临时日志、镜像、读盘缓存和快照，删除前复核归档内容，历史材料仍可打开或恢复。“历史任务材料”默认只列出 30 天以前的已结束任务，可改为 7 天或全部；清理归档与临时副本后仍保留小型任务摘要，已清理的诊断不能再导出。

清理不需要管理员认证，不自动执行或定时删除。保留当前输入快照、预览、活动或未知任务、尚待检查的失败刻录、归档不完整或索引无法识别的材料。共享快照只在全部引用任务都有完整归档且不再使用时列入清理。原始输入、已导出文件、光盘和已安装应用不在范围内；清理不会解除刻录锁。显示空间按实际分配块估算，APFS 共享块或系统快照可能延后空间回收。
